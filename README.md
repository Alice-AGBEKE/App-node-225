Description

Cet exercice consiste à creer un programme Java Script qui demande à l'utilisateur de saisir un nombre au clavier, puis affiche ce nombre dans le terminal.
Nous avons utiliser le module readline de Node.js.
Recupérer une valeur saisie par l'utilisateur.
Convertir la valeur saisie en nombre avec Number().
Afficher le resultat avec console.log().
